# 把《股市模拟》打包成 Windows exe

游戏本体就是一个 HTML 文件。有两种把它变成 exe 的路子，**结论先放前面**：

| 方案 | 产物 | 构建需要下载 | 什么时候选它 |
| --- | --- | --- | --- |
| **Neutralino**（当前默认） | **单个 exe，2.62 MB** | 约 8 MB | 想要体积小、拷给别人就能玩 |
| Electron（备选，配置已就绪） | 约 70~100 MB | 约 250 MB | 想要最成熟的生态与调试体验 |

## 目录约定

```
web/                          网页项目
  股市模拟.html                交付物：单文件游戏
  server.mjs                  本地预览服务器
  prepare-vendor.mjs          把图表库从 node_modules 同步到 vendor/
  vendor/lightweight-charts.js   （生成物，不入版本控制）

desktop/                      桌面打包相关的一切
  electron/                   Electron 主进程与构建脚本
  electron-builder.yml        Electron 打包配置
  neutralino/                 Neutralino 资源同步与产物清理脚本
  neutralino.config.json      Neutralino 配置
  resources/                  （生成物）Neutralino 资源目录
  bin/                        （生成物）Neutralino 运行时
  dist/                       （生成物）Neutralino 打包产物
  dist-electron/              （生成物）Electron 打包产物
```

两边的真源都是 `web/`——桌面打包只做拷贝，不改内容，不会出现"改了一份忘了另一份"。

---

## 方案一：Neutralino（2.62 MB）

### 为什么能这么小

它**不打包浏览器内核**，而是用系统自带的 WebView2——Windows 11 和打满更新的 Windows 10 都已经装了。所以 exe 里只有：Neutralino 运行时 2.32 MB + 你的游戏 0.30 MB。

实测数字：

| 组成 | 大小 |
| --- | --- |
| Neutralino 运行时（`neutralino-win_x64.exe`） | 2.32 MB |
| 游戏 HTML + 图表库 | 0.30 MB |
| **嵌入资源后的成品 exe** | **2.62 MB** |

### 三条命令

```powershell
npm install                 # 装依赖（含 neu CLI，217 KB），并把图表库同步到 web/vendor/
npx neu update              # 一次性下载 Neutralino 各平台运行时，约 8 MB
npm run neutralino:build    # 打包
```

前两条各跑一次即可，之后改完游戏只跑第三条（它会自动重新同步资源）。

产物：

```
desktop\dist\StockSim\StockSim-win_x64.exe    2.62 MB
```

**单文件、自包含。** 构建脚本带了 `--embed-resources`，游戏与图表库都嵌进了 exe；拷到任何地方（哪怕是空目录）双击就能玩，目标机器不需要 Node、不需要任何依赖。

脚本还会自动删掉 `neu build` 顺手生成的 macOS 与 Linux 二进制，让 `desktop/dist/` 里只剩一个可以拷走的东西。

### 运行时试跑（不打包）

```powershell
npm run neutralino:run
```

### 配置与脚本在哪

| 文件 | 作用 |
| --- | --- |
| [neutralino.config.json](../desktop/neutralino.config.json) | 窗口尺寸、标题、端口、运行时版本 |
| [prepare-resources.mjs](../desktop/neutralino/prepare-resources.mjs) | 把 `web/` 同步成 `desktop/resources/` |
| [prune-dist.mjs](../desktop/neutralino/prune-dist.mjs) | 清理非 Windows 产物 |

### 三个已经踩掉的坑

**1. `documentRoot` 必须指向包内的 `/resources/`，否则页面根本打不开。**
这是最严重的一个：Neutralino 打包时会保留 `resources/` 这层目录名，`documentRoot` 要指向它。写成 `"/"` 的话，服务器会在包根去找 `index.html`，于是**所有资源都返回 404**，WebView 里只显示"找不到 127.0.0.1 页面"。从 2.3 MB 的 exe 里看不出任何异常，进程活着、窗口标题也对。正确写法见 [neutralino.config.json](../desktop/neutralino.config.json)：`documentRoot: "/resources/"` + `url: "/"`。

**2. 端口必须固定，否则存档每次都会丢。**
Neutralino 的 `port` 若设成 `0`（随机端口），WebView2 每次启动的 origin 都不一样，而 localStorage 是按 origin 隔离的——结果是**每次打开游戏存档都清空**。所以配置里固定成了 `41888`。测试里专门有一条守着这个不变量。

**3. 图表库必须落在游戏期望的相对路径上。**
游戏加载链的第一级是相对路径 `vendor/lightweight-charts.js`，资源同步脚本把它放在 `resources/vendor/lightweight-charts.js`，相对位置与 `web/` 里完全一致，所以桌面版离线时也有完整 K 线图。放错了不会报错，只会静默退回内置的 Canvas 简易图——测试里也守着这条。

> 为什么用 `vendor/` 而不是 `node_modules/`：这个 HTML 是能单独拷走的交付物，不该知道 npm 的目录结构。`web/prepare-vendor.mjs` 负责从 `node_modules` 把库同步过去，挂在 npm 的 `postinstall` 上。

### 怎么自查打包结果

上面第 1 条说明：**"进程活着、窗口标题正确"完全不能证明页面加载成功**。真正的验证只有一个——把页面内容取回来：

```powershell
# 启动 desktop\dist\StockSim\StockSim-win_x64.exe 后：
curl.exe -s -o NUL -w "%{http_code}" http://127.0.0.1:41888/
```

返回 `200` 才算正常；返回 `404` 就是 `documentRoot` 写错了，具体原因可以在 exe 同目录的 `neutralinojs.log` 里看到（配置里已开启 `writeToLogFile`）。

顺带一提，默认的窗口标题取自配置而非页面，所以标题正确与否和页面是否加载成功没有任何关系。

`npm test` 里有一条端到端用例会自动做这件事：它拉起打包好的 exe、用 HTTP 取回首页、断言页面里含游戏内核脚本。它会在端口已被残留实例占用时直接失败——避免对着旧进程"假通过"。

### 存档位置

WebView2 的用户数据目录由 Neutralino 管理。想清档，在游戏里点「重开」即可。

## 方案二：Electron（约 70~100 MB）

体积降不下来的原因是它在结构上就把整个 Chromium 运行时塞进了你的程序里，压缩与裁剪只能把它从 120 MB 压到 70 MB 左右。

配置已经写好、随时可用，只是需要多下载约 250 MB 的工具链：

```powershell
npm run electron:setup    # 一次性，约 250 MB
npm run electron:dev      # 开发模式试跑
npm run electron:build    # 打包
```

### 会下载什么

**本机 `github.com` 时通时不通**，而 Electron 的二进制与 electron-builder 的打包器默认都从 GitHub 下载，所以两个脚本里写死了国内镜像：

```powershell
$env:ELECTRON_MIRROR = 'https://registry.npmmirror.com/-/binary/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR = 'https://registry.npmmirror.com/-/binary/electron-builder-binaries/'
```

不设镜像直接 `npm i electron`，一定会卡在下载二进制那一步。

| 内容 | 大小 | 默认来源 |
| --- | --- | --- |
| Electron 预编译二进制 | 100+ MB | `github.com/electron/electron/releases` |
| winCodeSign | 约 5 MB | GitHub releases |
| nsis 打包器 | 约 2 MB | GitHub releases |

### 相关文件

| 文件 | 作用 |
| --- | --- |
| [main.cjs](../desktop/electron/main.cjs) | 主进程：开窗口、加载游戏、F11 全屏、外链交系统浏览器 |
| [electron-builder.yml](../desktop/electron-builder.yml) | 打包配置：便携版 + NSIS 安装版 |
| [setup.ps1](../desktop/electron/setup.ps1) | 装工具链（含镜像） |
| [build.ps1](../desktop/electron/build.ps1) | 产出 exe |

安全设定上，游戏是纯网页不需要 Node，所以 `nodeIntegration: false`、`contextIsolation: true`、`sandbox: true` 三项全部关掉。

## 该选哪个

- **只是想双击就玩、想拷给别人** → Neutralino。2.62 MB，几分钟就能出结果。
- **想接原生能力**（托盘、菜单、自动更新、系统对话框）或需要成熟的调试工具链 → Electron。代价是体积和 250 MB 的下载。

两者的配置现在都在仓库里，互不影响，随时可以切换。
