# 把《股市模拟》打包成 Windows exe

游戏本体就是一个 HTML 文件。Electron 负责给它套一个原生窗口，再连同一个 Chromium 运行时一起打包成 exe，于是不需要浏览器也能双击开玩。

**本文只说明工具怎么用。工具链的实际下载与打包动作，等你确认后再执行。**

## 用到的三样东西，各干什么

| 名称 | 作用 | 装在哪 |
| --- | --- | --- |
| Electron | 提供 Chromium + Node 运行时，让网页变成桌面程序 | 项目 `devDependencies` |
| electron-builder | 把 Electron 应用打成 exe 与 NSIS 安装包 | 项目 `devDependencies` |
| NSIS、winCodeSign | electron-builder 内部再去下载的打包器与签名工具 | 全局缓存，不进项目 |

## 会下载什么、多大、从哪下

这一步最需要先讲清楚，因为**本机的 `github.com` 是不通的**（`api.github.com` 通，但网页与 release 下载都不通）。

| 内容 | 大小 | 默认来源 | 本机能否直连 |
| --- | --- | --- | --- |
| `electron` npm 包 | 约 1.1 MB | npm registry | ✅ 能（已配 npmmirror） |
| Electron 预编译二进制 | **100+ MB** | `github.com/electron/electron/releases` | ❌ **不通** |
| winCodeSign | 约 5 MB | GitHub releases | ❌ 不通 |
| nsis 打包器 | 约 2 MB | GitHub releases | ❌ 不通 |
| **合计** | **约 250 MB** | | |

所以两个脚本里都写死了镜像地址，不设的话安装一定会在"下载二进制"那一步失败：

```powershell
$env:ELECTRON_MIRROR = 'https://registry.npmmirror.com/-/binary/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR = 'https://registry.npmmirror.com/-/binary/electron-builder-binaries/'
```

这两个镜像我已经实测可达（HTTP 200）。

## 三个命令

### 1. 装工具链（一次性）

```powershell
npm run electron:setup
```

约 250 MB、几分钟。装完 `devDependencies` 里会多出 `electron` 与 `electron-builder`，`package-lock.json` 会更新。

### 2. 开发模式试跑（不打包）

```powershell
npm run electron:dev
```

直接用 Electron 打开游戏，秒开。用来确认窗口尺寸、图表、存档读写都正常，再去做打包这一步。

### 3. 打包成 exe

```powershell
npm run electron:build
```

产物在 `dist-electron/`：

| 文件 | 说明 |
| --- | --- |
| `StockSim-1.0.0-portable.exe` | 免安装便携版，双击即玩，可以直接拷给别人 |
| `StockSim-1.0.0-setup.exe` | 安装版，可选安装目录、建桌面快捷方式 |

## 窗口与行为

| 项 | 设定 | 改在哪 |
| --- | --- | --- |
| 默认尺寸 | 1440 × 920 | [`electron/main.cjs`](../electron/main.cjs) |
| 最小尺寸 | 360 × 600（游戏本身适配窄屏） | 同上 |
| 全屏 | F11 切换 | 同上 |
| 菜单栏 | 已移除 | 同上 |
| 外链 | 交给系统浏览器打开，不在应用内开新窗口 | 同上 |
| 启动底色 | `#e7ebf0`，与游戏大厅同色，避免启动瞬间闪白 | 同上 |

## 安全设定

游戏是纯网页，不需要任何 Node 能力，所以三项全部关掉：

- `nodeIntegration: false`
- `contextIsolation: true`
- `sandbox: true`

渲染进程拿不到 Node API，即使页面里的脚本被替换也翻不出沙箱。

## 存档在桌面版里放在哪

游戏用 localStorage 存盘，Electron 把它放在用户数据目录：

```
%APPDATA%\StockSim\Local Storage\
```

想彻底清档，删掉 `%APPDATA%\StockSim` 整个目录即可（游戏内点「重开」也能重开一局）。

## 打包内容清单

[`electron-builder.yml`](../electron-builder.yml) 的 `files` 只列了四样：

- `股市模拟.html` —— 游戏本体
- `electron/main.cjs` —— 主进程
- `package.json`
- `node_modules/lightweight-charts/dist/lightweight-charts.standalone.production.js` —— **图表库必须带上**，否则桌面版离线时会退回内置的 Canvas 简易图

其余开发文件（测试、文档、服务器脚本）都不会进包。

## 可选调整

**换图标**：放一个 256×256 的 `build/icon.ico`，再取消 `electron-builder.yml` 里 `icon:` 那行的注释。不换就用 Electron 默认图标。

**让 exe 显示中文名**：`productName: StockSim` 现在是 ASCII，目的是让第一次构建尽量顺利（NSIS 对非 ASCII 产品名偶有编码问题）。想要中文名就改成 `productName: 股市模拟`，窗口标题本来就已经是中文了。若构建报编码错误就改回来。

## 已知注意事项

- **必须走镜像。** 不设镜像变量直接 `npm i electron`，会在下载二进制时报 `RequestError: connect ETIMEDOUT ... github.com`。
- **首次打包更慢。** electron-builder 第一次运行还要下 winCodeSign 与 nsis，之后会缓存复用。
- **没有代码签名。** exe 运行时 Windows SmartScreen 可能提示"未知发布者"。自用无碍；要消除得买代码签名证书。
- **没有自动更新。** 单机游戏不需要 updater，也就省掉了签名密钥与更新服务器。
- **asar 打包。** 游戏与图表库都打进 `app.asar`，用户看到的是一个干净的程序目录，不是一个散落的 HTML。
