## 3. 交易机制

### 3.1 每个交易日的两步结构

现实中的股民是**在盘中基于已公开信息下单**，收盘后才知道当天结果。为彻底避免"用当日 K 线决定当日成交"的未来函数，每日拆成两步：

```
① 盘前决策：玩家只看到 ≤ T−1 日的 K 线、持仓、以及 T 日已公布的新闻公告，
            下达市价单 / 限价单（T 日有效）
② 收盘揭晓：结算 T 日 —— 成交、涨跌停校验、费用扣除、分红派发、T+1 解冻，
            然后展示 T 日 K 线与当日新闻结果，进入 T+1
```

### 3.2 两种委托

| 委托类型 | 成交规则 | 成交价 |
|---|---|---|
| 市价单 | T 日必然尝试成交（除非涨跌停封锁） | **T 日收盘价** × (1 ± 滑点) |
| 限价单（买） | T 日 `low ≤ 限价` 触发，否则继续挂 | `min(限价, T 日开盘价)` |
| 限价单（卖） | T 日 `high ≥ 限价` 触发，否则继续挂 | `max(限价, T 日开盘价)` |

- 有效期：**当日有效 / 3 日有效**，未成立可随时撤单；3 日到期自动失效并提示。
- 限价单成交价不会优于限价，也不会劣于开盘价。

### 3.3 T+1（严格实现）

- **买入成交在 T 日 → 该股 T+1 才可卖**；T 日内卖出委托被拒绝并提示"当日买入，明日可卖"。
- **卖出资金 T 日即可用于买入**（与 A 股一致：资金 T+0 可用、T+1 可提现）。
- 持仓界面区分 `总持仓 / 可卖数量`，冻结数量可见。

### 3.4 费用与规则

| 项目 | 规则 |
|---|---|
| 佣金 | 万分之 2.5，**最低 5 元**，买卖双向 |
| 印花税 | 卖出 0.05% |
| 过户费 | 双向 0.001% |
| 滑点 | `0.05% + (订单额 / 当日成交额) × 0.5%`，上限 0.5% |
| 最小单位 | 100 股整手 |
| 流动性约束 | 单笔订单不超过当日成交额的 3% |
| 现金利息 | 年化 1.5%，按日计提 |
| 做空 / 杠杆 / 停牌 | 均无 |

> 45 天里交易次数本就少，"最低 5 元佣金"的存在感反而更强：它会明确惩罚"每次只买 1 手"的碎单行为。

### 3.5 资金冻结（v1.3）

国内券商挂买单时会**立即冻结**一笔资金，可用资金随之减少 —— 否则玩家能连挂好几笔"全仓"，结算时只有一笔有钱成交，剩下的变成"资金不足"，看起来像 bug。

| 项 | 规则 |
|---|---|
| 冻结时机 | 买入委托**下单瞬间** |
| 冻结金额 | `数量 × 昨收价 × (1 + 滑点上限 + 1%)`，按最坏成本预估 |
| 可用现金 | `账面现金 − 挂单冻结` |
| 释放时机 | 成交（按实际成交额扣款）、撤单、限价失效、涨跌停拒单 |
| 总资产口径 | 仍含冻结资金（钱还是玩家的） |

实现上**冻结额由未成交买单推导**，而不是维护一个单独的计数器：撤单 / 成交 / 失效三条路径都得记得释放，漏一条就永久占住资金；推导出来则不可能漏，也不会因反复加减产生浮点漂移。

> 冻结是**软预留**：预估按昨收价算，而市价单按当日收盘价成交。遇到大幅高开的股票，实际扣款仍可能超过冻结额，所以结算时保留了"按可负担整手数缩减"与"资金不足拒单"两道兜底。

## 4. 价格模型

### 4.1 三层因子结构

```
市场因子   r_m,t = μ_state + σ_t·z_t + J_m,t
行业收益   r_i,t = β_i·r_m,t + h_i,t + σ_i^sec·ε_i,t
个股收益   r_j,t = β_j·r_i(j),t + a_j + σ_j^idio·η_j,t + Jump_j,t
```

`z, ε, η` 为标准化学生 t（ν=4），保留厚尾。

### 4.2 状态机（适配 45 天）

| 状态 | 平均持续 | 日漂移 | 目标年化波动 | 特征 |
|---|---|---|---|---|
| 上涨 | 12 日 | +0.16% | 18% | 普涨，回撤浅 |
| 震荡 | 9 日 | +0.01% | 20% | 结构分化最大 |
| 下跌 | 10 日 | −0.18% | 26% | 反弹即卖点 |
| 急跌 | 3 日 | −0.60% | 45% | 恐慌抛售，跳跃×5 |

45 天内期望形成 **1~2 段完整行情**（如"上涨 12 → 震荡 9 → 下跌 10 → 急跌 3 → 反弹 11"）。

### 4.3 波动率

- GARCH(1,1)：**α = 0.12, β = 0.80**（α+β = 0.92，冲击半衰期约 8 个交易日，适配 45 天窗口）；急跌状态 α 提至 0.20。
- 波动率聚集在 45 天窗口内依然清晰可见（"大跌之后还是大波动"）。

### 4.4 三层价格突变体系（v1.2 新增，本次核心）

价格突变分三层，**互不叠加**：

| 层级 | 来源 | 幅度 | 频率 | 可归因性 |
|---|---|---|---|---|
| **A. 事件驱动跳空** | 公司/行业/宏观事件，**必有新闻** | 单日受涨跌停约束；暴雷以**连续跌停**累计 **−10% ~ −27%**，暴涨 **+8% ~ +20%** | 重大事件 1~2 次/局 | ✅ 完全可归因 |
| **B. 随机跳动** | 纯随机，**无任何消息面** | 个股 **±2.5% ~ 6%**；市场级（指数）**±1.5% ~ 3%** | **≤ 10 次 / 45 天，且 ≤ 1 次 / 天** | ❌ 不可预测、不可归因 |
| **C. 常规波动** | 因子模型 + GARCH | 日内正常幅度 | 每个交易日 | 部分可归因 |

**B 层的约束实现（严格按你的要求）**：

1. 开局一次性抽取跳动日程：`N ~ Binomial(45, 0.22)`，**硬上限 10**；再从 45 天中抽出 N 个**互不重复**的日子 → 从结构上保证「一天内不存在多次跳动」。
2. 每个跳动日按 **20% 市场级 / 80% 个股级** 决定类型；个股级按 `σ_j^idio` 加权选股（小市值、题材股更容易跳）。
3. 若某股当日已有 A 层事件冲击，则跳过该股、改选其他股票（避免叠加放大）。
4. 幅度**硬上限 6%**，严格小于 A 层的暴雷（累计 ≥10%）与暴涨（≥8%）；方向约 45% 正 / 55% 负，体现"下跌更突然"。
5. B 层跳动的存在意义：**它是不可分散的个股黑天鹅**——玩家能做的最优应对是仓位管理，而不是预测。这正是本作想传达的风险观。

### 4.5 涨跌停（真实板块规则）

| 板块 | 涨跌停 | 数量 | 覆盖行业 |
|---|---|---|---|
| 主板 | **±10%** | 18 只 | 白酒食品、银行金融、医药生物、房地产建筑、有色金属、农业养殖 |
| 创业板 | **±20%** | 9 只 | 新能源车、军工航天、互联网传媒 |
| 科创板 | **±20%** | 3 只 | 半导体芯片 |
| ST / *ST（动态） | **±5%** | 0~2 只 | 由暴雷事件触发状态变更 |

**ST 状态变更**：若某公司发生"财务造假 / 立案调查"类暴雷，**次日起标记为 ST**，涨跌停收窄至 ±5%，并伴随持续的资金撤离漂移。这是真实 A 股最凶险的场景之一，也让"暴雷"不止是单日下跌。

**涨跌停封锁**：

| 情形 | 结果 |
|---|---|
| 收盘价 = 涨停价 | **买单不成交**（排队买不到）；卖单正常成交 |
| 收盘价 = 跌停价 | **卖单不成交（想割肉也割不掉）**；买单正常成交 |
| 一字板（`low = high = 涨停`） | 全天无成交，买卖单均不成交 |

> 说明：真实 A 股的涨跌停按板块区分，本作按真实规则实现；股票**代码仍用 `88xxxx` 虚构号段**（你此前明确要求不使用真实代码），因此"板块"作为独立属性标注在个股信息上，而不是靠代码前缀体现。

### 4.6 个股参数

| 参数 | 分布 |
|---|---|
| β_j（对行业） | N(1.0, 0.25)，截断 [0.4, 1.8] |
| σ_j^idio 年化 | 25% ~ 60%（小市值、创业板/科创板偏高） |
| a_j 年化 alpha | N(0, 8%)，全程不向玩家暴露 |

### 4.7 价格合成与日内形态

- `P_t = P_{t−1} × (1 + clip(r_t, ±板块涨跌停))`，触及时标记涨停/跌停并影响撮合。
- 最低价保护 0.5 元；除息日价格下调、玩家现金增加。
- 日内 OHLC 用布朗桥生成，恒满足 `low ≤ min(open,close) ≤ max(open,close) ≤ high`。

### 4.8 成交量与流动性

```
换手率 = base_j × (1 + 2.5·|r_j,t|) × (0.6 + S_t/100) × 季节因子(春节前后 0.7) × LogNormal(0, 0.4)
```

成交额决定流动性约束（单笔 ≤ 3%）与滑点大小。

## 5. 基本面、财报与分红

- **业绩预告（第 8~14 日）**：贴合 1 月现实；超预期者在未来 10 日产生向上漂移（PEAD）。
- **年报快报（第 28~34 日）**：兑现或打脸预告——"预告好、快报差"正是杀跌来源。
- **估值回归**：`PE = 价格 / EPS_ttm`；处行业后 10% 分位时产生向上回归漂移，前 10% 分位向下。
- **现金分红**：**2~3 家**在第 33 日前后做特别分红 / 中期分红除息，股息率 1.5%~3%。
- **送转股**：不做。

## 6. 新闻与事件系统

**编排顺序：先生成 45 天事件时间线，价格再由事件驱动**，保证"读到的新闻"与"随后的走势"必然自洽。

| 层级 | 事件示例 | 强度 | 持续性 |
|---|---|---|---|
| 宏观 | 降准降息 / 监管表态 / 外部市场大跌 / 经济数据超预期 | 中~强 | 3~10 日 |
| 行业 | 产业政策扶持 / 需求爆发 / 原材料涨价 / 竞争加剧 / 出口限制 | 中~强 | 5~20 日 |
| 公司 | 业绩预告超预期 / 大额订单 / 并购重组 / 股东减持 / 财务暴雷 / 产品获批 | 弱~极强 | 1~30 日 |

- 每日 **2~5 条**新闻，重大事件约 1~2 次/局。
- 极强负面事件（财务暴雷）触发**连续跌停**并可能变 ST。
- **约 30% 消息为"传闻"**（不驱动价格或反向），UI 标注「公告」/「传闻」。
- 文案由 3~6 个模板 + 槽位生成。
- **UI 保留上一天的新闻**（v1.3）：用变淡 + 一条「昨日」分隔做视觉降级，当天仍是主角。只显示当天会丢线索 —— 前一天的公告往往正是当天走势的解释，而玩家读完昨天的消息、点了结算，再回来看就没了。只保留一天，不做历史累积。

## 7. 股民情绪系统

- **情绪指数 S ∈ [0,100]**，初始 50，OU 均值回归；驱动项为近 5 日大盘涨跌、成交量、新闻情绪净额。
- 影响：短期漂移 `+(S−50)/50 × 0.15%/日`、波动率乘数 `(0.8 + S/100)`、成交量、题材股弹性（传媒/军工额外 ×1.3）。
- **极端反转**：`S > 85` 或 `S < 15` 时未来 3 日反向概率 58%。
- UI：情绪温度计 + 档位（冰点 / 低迷 / 平静 / 活跃 / 狂热）+ 历史分位。

## 8. 可预测性预算（现实强度）

原则：**信号真实存在但都很弱，且各自有失效状态**——不存在全天候公式。

| 信号 | 触发条件 | 未来超额 | 命中率 | 失效状态 |
|---|---|---|---|---|
| 行业轮动动量 | 行业近 10 日强于大盘 > 4% | 未来 10 日 +0.8% | 54% | 下跌 / 急跌中失效，甚至反向 |
| 业绩预告漂移 | 预告增速超预期 | 未来 10 日 +1.5% | 57% | 大盘下跌时效果减半 |
| 估值回归 | PE 处行业后 10% 分位 | 未来 20 日 +1.5% | 55% | 仅震荡 / 上涨状态有效 |
| 情绪反转 | S > 85 或 S < 15 | 未来 3 日反向 0.3%/日 | 58% | 强趋势中失效 |

**目标体验分布**（45 日尺度）：
- 大盘自身 45 日收益区间 **−12% ~ +15%**，中位数约 +2%。
- 追涨杀跌 / 频繁交易者：多在 −15% ~ +3%，并被手续费持续磨损。
- 认真读公告、控制仓位、结合大盘状态做轮动的玩家：55%~65% 概率跑赢基准 3%~10%。
- 极端冒险者：+25% 或 −20% 均有可能。

## 9. 结算与评级（45 日尺度）

主指标为**相对 HXCI 的超额收益**，辅以绝对收益、最大回撤、胜率、交易次数、**手续费总额**。

| 相对基准超额 | 称号 |
|---|---|
| < −10% | 韭菜之王 |
| −10% ~ −3% | 交学费的韭菜 |
| −3% ~ +3% | 与大盘同步 |
| +3% ~ +10% | 跑赢大盘 |
| +10% ~ +20% | 老手 |
| > +20% | 股神 |

结算页附**关键交易回放**（最大盈利 / 亏损的三笔 + 当时新闻），并单独列出**手续费总额**。

## 10. 技术架构与前端

### 10.1 模块

| 模块 | 职责 |
|---|---|
| `RNG` | mulberry32 种子随机数，同种子完全可复现 |
| `WorldGen` | 30 只股票参数、板块归属、45 天事件时间线、**跳动日程** |
| `MarketSim` | 逐日生成 OHLCV，封装未来数据 |
| `Portfolio` | 现金、持仓、成本、T+1 冻结与解冻 |
| `Broker` | 撮合（市价/限价）、费用、滑点、板块涨跌停、流动性校验 |
| `NewsFeed` | 事件文案渲染与公告/传闻标记 |
| `Emotion` | 情绪指数更新 |
| `Scoring` | 结算与评级 |
| `Persistence` | localStorage 存档 / 读档 |
| `UI` | 面板、图表、交互 |

- **防剧透**：未来数据全部封装在 `MarketSim` 闭包，UI 只能经 `sim.day(t)` 读 `≤ t` 的数据。
- **预生成**：30 × 45 = 1350 根 K 线，耗时 < 20ms，内存 < 300KB。
- **存档**：`{ version, seed, currentDay, cash, positions[], orders[], trades[], flags{} }`，带版本号。
- **图表**：Lightweight Charts 画 K 线、资产曲线、指数对比。

### 10.2 界面

- **标题**：《股市模拟》—— 副标题「45 个交易日 · 初始资金 10 万元」
- **视觉方向**：题材是"散户在 A 股营业部"，采用行情终端语言，**红涨绿跌**（中国习惯，与西方相反）作为核心色彩语义；刻意避开"奶油底 + 衬线大标题 + 陶土色"与"近黑 + 荧光绿"两类通用 AI 套路。
- **桌面三栏**：左＝账户与持仓；中＝K 线与个股详情；右＝新闻流与情绪面板；底部＝委托与交易区。
- **移动端**：底部 Tab（持仓 / 行情 / 新闻 / 交易）。
- **字体**：中文黑体 + 数字等宽（`tabular-nums`），价格列严格对齐。
- **可达性**：红绿之外用 ↑↓ 符号冗余表达涨跌；键盘可操作；焦点可见；`prefers-reduced-motion` 生效。
- **动效**：只在成交回执、收盘揭晓、暴雷事件出现。
- **快捷数量自动判方向**（v1.3）：交易面板不设"买入/卖出"切换，而是看选中标的有没有可卖持仓 —— 有就按**持仓**算（半仓 = 可卖的一半，全仓 = 全部可卖），没有就按**可用现金**算。口径会写在数量提示里，免得玩家点了「全仓」才发现算的是卖出。代价是持有某只股票时想加仓，快捷数量给的是卖出量。

## 12. 已知取舍

- **代码与板块的分离（已决议）**：涨跌停按真实板块规则实现，但代码**确定沿用虚构 `88xxxx` 号段**，因此板块作为独立属性标注，而非靠代码前缀体现。这样可确保代码不与任何真实上市公司重合，满足"不使用真实公司名称与代码"的要求。
- **随机跳动的方向偏负**（45% 正 / 55% 负）：体现真实市场中"下跌更突然"，但也意味着玩家承受的个体风险略高于对称情形，已在平衡中通过稍高的市场风险溢价补偿。
- **涨跌停 clip 会轻微扭曲收益分布**：刻意为之（现实如此）。
- **预生成意味着内存中存在"未来"**：由闭包隔离，无法防御手改 localStorage——单机游戏可接受。

## 13. 决议记录

设计已确认，进入编码阶段。已锁定的关键决议：

| 决议 | 结论 |
|---|---|
| 游戏名 | 《股市模拟》 |
| 时间跨度 | 45 个交易日（约 9~10 周），逐日推进，无跳过 / 快进 |
| 股票代码 | 虚构 `88xxxx` 号段，不与任何真实代码重合 |
| 涨跌停 | 真实板块规则：主板 ±10%、创业板 / 科创板 ±20%、ST ±5% |
| 委托 | 市价单按当日收盘价成交 + 限价单（当日 / 3 日有效），严格 T+1 |
| 分红 | 保留（窗口内 2~3 家特别 / 中期分红除息） |
| 空仓计息 | 年化 1.5%，按日计提 |
| 随机跳动 | ≤10 次 / 45 天，≤1 次 / 天，幅度硬上限 6%（小于事件驱动的暴雷 / 暴涨） |
| 难度 | 现实强度，每个可预测信号均有失效状态 |
